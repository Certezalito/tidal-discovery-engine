# Data Model: Fix Duplicate Genre Playlists

## Key Entities

### Target Folder
- **Description**: The Tidal folder designated by the user to hold genre playlists.
- **Attributes**: `id` (str), `name` (str)
- **Relationships**: Contains many `Genre Playlist`s.

### Genre Playlist
- **Description**: A user playlist generated by the system to contain tracks of a specific genre.
- **Attributes**: `id` (str), `name` (str), `created` (datetime)
- **Validation Rules**: 
  - Unique constraint on `name` within the context of the Target Folder.
  - State transitions during sync:
    1. Fetch all paginated playlists in the folder.
    2. Group by normalized `name.lower()`.
    3. If multiple exist for a name, select the oldest (by `created` or index) and delete the rest.
    4. Sync the selected playlist's tracks to match the new library state.
